# Inferno Knight

Browser HTML5 platformer by Aarav Pavuluri.

## Play online

**GitHub Pages:** https://aaravpvcsai.github.io/Inferno-Knight/

(If that 404s, enable Pages: **Settings → Pages → Deploy from branch → `main` / root → Save**. Then wait 1–2 minutes.)

## Files

- `index.html` — main game (single-file)
- `.nojekyll` — required for Pages

## Local

Open `index.html` in any modern browser.
